🤖 Aide agent — jouer sans navigateur

Trois façons de piloter une partie (état partagé dans .chess_game.json, suivi live dans ce navigateur) :

1. CLI chess … --json

chess new --json
chess moves --json            # coups légaux (UCI + SAN)
chess move e2e4 --json        # ou en SAN : chess move Nf3 --json
chess status --json           # turn, result, version, opening…
chess ai-move --level club --json
chess wait --color w --timeout 60 --json   # bloque jusqu'au tour des Blancs
chess puzzle --level 2 --json && chess solve d8h4 --json
chess analyze --json · chess games --json · chess pgn

2. Serveur MCP (JSON-RPC stdio)

python -m chess.mcp

Outils : new_game, get_board, get_status, legal_moves, play_move, ai_move, analyze_position, get_pgn, puzzle, solve, analyze_game. Déclaration : vibe mcp add chess --transport stdio --command .venv/bin/python --arg -m --arg chess.mcp (voir README).

3. Skill

skills/chess-cli/SKILL.md — contrat --json complet, boucle de jeu, gestion des erreurs (rc 1 + liste des coups légaux), agent vs agent avec wait.
